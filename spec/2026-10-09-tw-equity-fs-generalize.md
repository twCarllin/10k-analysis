## 1. 資料模型變更（`statements.py`，向後相容）

### 1.1 `StatementRow` 新增欄位
- `code: str | None` — 剝除的會計代碼原文（如 `"1100"`、`"A21200"`），無 → None。
- `columns: list[float | None]` — 該列**全部期間欄**的金額（依表頭欄序，不含 %）。年度財報為 2 個值。

### 1.2 `StatementLedger` 新增欄位
- `column_periods: dict[str, list[str]]` — 每張表的欄位期間標籤，鍵 `"bs"`／`"is"`／`"cf"`。標籤格式（民國年、兩位月日）：時點 `"115-06-30"`；期間 `"115-01-01~115-06-30"`。年度財報：BS `["114-12-31","113-12-31"]`，IS／CF `["114-01-01~114-12-31","113-01-01~113-12-31"]`。解析不到 → 該表為空 list。
- `current_col` / `prior_col: dict[str, int | None]` — 每張表的 `current`／`prior` 取自 `columns` 的哪一欄。
- `to_dict()` 輸出上述新鍵；既有鍵與既有值不變。

### 1.3 `current`／`prior` 的選欄規則（使用者 2026-10-09 裁示）
- **BS**：current＝第 1 欄（最新時點）；prior＝**上年度末**欄（月日為 `12-31`、年＝current 年 − 1）；找不到 → 第 2 欄。
- **IS**：4 欄時 current／prior＝**年初至今**兩欄（期間起日 `01-01` 者，依年序）；2 欄時＝第 1、2 欄。
- **CF**：第 1、2 欄。
- `period_current`／`period_prior` 字串維持既有語義（民國年，如 `"115"`／`"114"`），取自 BS 的 current／prior 欄；年度財報結果與現況相同。
- 3653 年度財報：每列 `current`／`prior` 值與本 run 前完全相同（回歸測試鎖定）。

## 2. 解析規則（`parse_statement_lines` 與相關函式）

### 2.1 表頭偵測（每張表、每頁重新偵測）
- 期間標題：支援阿拉伯數字（含字間空白）、`115.6.30` 點式、中文數字（`一一五年六月三十日`、`一一四年十二月三十一日`）；IS 跨兩列的起訖（`115年4月1日` ＋ 下一列 `至6月30日`）合併成期間。單一列只寫月日的簡寫（如 1303 表題 `一一四年十二月三十一日及六月三十日`）以表頭欄列為準。
- 欄數 n＝表頭欄列偵測到的期間數；有 `%` 欄標題（`金額%`）→ 每欄 2 個 token。
- 左右並排（F9）：同一表頭列期間數為 2n 且表頭含「資產」與「負債」→ 標記並排頁。
- 表頭列、`代碼…金額%`、`金額%…`、`項目`、純期間續列（`至6月30日…`）、`(接次頁)`、`(承前頁)`、`(續次頁)` 一律跳過，不進 rows。

### 2.2 列解析
- 會計代碼（F2）：列首 token 為 `^\d{4}$`，或列首 token 開頭符合 `^(?:[A-Z]{1,4}\d{0,6})` 且其後緊接中文 → 剝除為 `code`，不當金額。
- 括號附註（F3）：續行合併後，從 label 移除以 `(附註` 開頭的**成對**括號（含巢狀）；合併前跨列的未閉合 `(附註…` 片段要能在合併後被移除。
- 附註欄變體（F4）：`_NOTE_RE` 擴充接受 `六.1`、`四及六.1`、`四、六.21及七` 型。
- 金額分配：token 數＝2n（有 %）→ 依序 (金額, %) 成對；token 數＝n → 全為金額（如 EPS 列）；其他數量 → `columns` 依可確定的規則填入，無法確定時該列 `columns` 全 None、`current`／`prior` 為 None，並記入 ledger 新欄 `parse_warnings: list[str]`（`"<st> p<頁> <label>: <n> tokens"`）。
- 左右並排（F9）：每列先切成左右兩半，各成一條獨立 stream（各自的續行合併與 section）；切點以右半的會計代碼 token（`^[23]\d{3}$`）為主，無代碼時以「左半金額 token 數達 2n（或 n）」為界。左半 → 資產區，右半 → 負債及權益區；輸出順序：左 stream 全部列，再右 stream。
- 群組標題帶冒號（F8）：比對前去掉結尾 `:`。

### 2.3 單位（F6）
`unit` 支援 `單位：…`、`(金額均以…為單位)`、`(金額除每股盈餘外，均以…為單位)`；取幣別＋單位詞（如 `新台幣千元`、`新臺幣仟元`）。

### 2.4 三表篩頁
維持帳本 Spec §2.2（頁首 3 列含表名）。若表名在第 4–5 列（表頭列較多的公司），放寬到頁首 5 列。
續頁：已選入至少 1 頁後，下一頁頁首 5 列含 `(承前頁)`／`(續前頁)`／`(續)`（NFKC 後比對）且不含其他兩張表的表名、也不含 `權益變動表` → 視為同表續頁，一併選入；否則停止（主 flow 2026-10-09 裁決，來源：2059 CF 第 8 頁頁首為 `（承前頁）`）。

### 8.3 解析器補強（版面）
1. **科目後黏附註、無括號**（2317、4958、3017）：label 尾端連續的附註 token（中文數字章節 `六(九)(三十五)及七`、`六(二十三)、七及十四`、`(四)/(六).28`、`(六).1` 型）剝除到 `note`。剝除只在 label 尾端、且剝除後 label 非空時進行；不得剝掉科目本身含的括號字（如 `營業利益(損失)`、`其他權益-國外營運機構財務報表換算之兌換差額`）。
2. **含 `x` 的代碼**（2454、6505）：列首 `^\d{1,3}[xX]{1,3}$`（如 `11xx`、`1xxx`、`15xx`）視為會計代碼剝除。
3. **IS 期間標題變體**（2454、6505）：`一一五年第二季`／`一一四年第二季`／`一一五年上半年度`／`一一四年上半年度` 型 → 第 N 季＝該季三個月、上半年度＝01-01~06-30；表頭只寫起日（`115年4月1日` 而迄日在他處）時，以表題列的迄日補齊。目標：`column_periods["is"]` 為 4 個期間、選欄正確。
4. **CF／BS 現金調節**（2344、3037）：CF 內「現金及約當現金之組成」／「期末現金及約當現金之調節」區塊中的 `資產負債表帳列之現金及約當現金`（含 `合併資產負債表帳列之現金及約當現金` 變體）→ 新 key `cash_per_bs_in_cf`。勾稽 `cf_ending_eq_bs_cash` 的 lhs：有 `cash_per_bs_in_cf` 時用它，否則用 `cash_ending`。勾稽名稱與數量不變。CF 頁選擇須涵蓋此區塊所在的續頁（2344 為 p10，頁首 `（承前頁）`）；若續頁在 `fs_cf` 錨點範圍外，允許延伸 1 頁（僅限頁首含承前頁且頁內無其他表名）。
5. 調節區塊中重複出現的 `期末現金及約當現金餘額` 不得覆蓋 CF 主體的 `cash_ending`（取第一列，現況即如此，加測試鎖定）。
