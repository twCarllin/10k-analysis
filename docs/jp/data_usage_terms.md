# データ利用条件 / 資料使用條款

## logmi Finance 逐字稿資料使用說明

### 資料來源

本系統使用 [logmi Finance](https://finance.logmi.jp/)（ログミーファイナンス）提供的法說會（決算説明会）逐字稿。

logmi Finance 是日本最大的免費法說會逐字稿媒體，由株式会社ログミー（logmi, Inc.）營運。

### 著作権

logmi Finance が提供する逐字稿コンテンツは、株式会社ログミーが著作権を保有しています。

逐字稿の著作権は logmi 及び元の発表者に帰属します。

### 自用・研究目的

本システムは以下の用途に限り logmi コンテンツを利用します：

- 個人投資研究（自用）
- 財務分析モデルへの入力データとしての活用
- 非商業目的の情報整理

**商用利用・大量転載**については、株式会社ログミーの利用規約に従い、事前に許諾を得る必要があります。

### 利用に際しての注意事項

1. **商用利用禁止**：本システムで生成した分析レポートを商業目的で第三者に販売・配布することはできません。
2. **自用 OK**：個人の投資判断補助・社内研究目的での利用は許容範囲内とみなします。
3. **大段転貼禁止**：逐字稿の大部分をそのままコピーして第三者に共有することは避けてください。引用は要約・分析の補足として最小限にとどめること。
4. **robots.txt 遵守**：スクレイピングは logmi の robots.txt を確認した上で実施し、サーバーへの過負荷を避けるために適切なレート制限（1 req/sec 以下）を設けています。

### 使用限制摘要（繁體中文）

| 用途 | 是否允許 |
|------|---------|
| 個人投資研究（自用） | 允許 |
| 社內非商業研究 | 允許 |
| 生成分析報告供內部使用 | 允許 |
| 商業銷售分析報告 | 不允許（需向 logmi 申請授權） |
| 大段逐字稿轉貼至公開平台 | 不允許 |
| 爬取資料轉售 | 不允許 |
